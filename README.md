# John Calkins Portfolio

Astro-hosted version of the exported Webflow portfolio, structured for static hosting on Cloudflare Pages.

## Local Preview

```sh
npm install
npm run dev
```

Open `http://127.0.0.1:4321`.

## Build

```sh
npm run build
```

The production site is generated in `dist/`.

## Cloudflare Pages

Use these build settings:

- Framework preset: `Astro`
- Build command: `npm run build`
- Build output directory: `dist`
- Node version: `22.12.0` or newer

## Content

- Page metadata lives in `src/data/webflow-pages.ts`
- Exported page bodies live in `src/webflow/pages/`
- Shared Webflow shell is in `src/layouts/WebflowLayout.astro`
- Routes are generated by `src/pages/index.astro` and `src/pages/[slug].astro`
- Exported assets live in `public/images`, `public/fonts`, `public/css`, and `public/js`

## Webflow Export Notes

The exported `.html` files were split into reusable Astro route metadata and individual page body partials, so shared head/scripts are not duplicated across every page. Internal `.html` links and relative asset paths were rewritten to clean routes and root-relative local assets. The Webflow password-protected `401` page was intentionally removed.
